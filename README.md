## Temperaturas por Ciudad

esta aplicacion de Java que nos sirve para cargar las temperaturas diarias desde un archivo de CSV, tambien grafica su promedio por ciudad e indica la ciudad mas y menos caluriosa de una fecha.

## Estructura de carpetas

El proyecto contiene la carpeta `src`, que incluye:

- `controladores`
- `datos`
- `modelos`
- `servicios`
- `vistas`

## Ejecutar

Se debe ejecutar 

- `App.java`
